# Amazon Sales Data Analysis

## 📊 Project Overview

Amazon Sales Data Analysis is a data analytics project focused on analyzing Amazon product and order-related data to identify patterns, trends, and useful business insights.

The project uses an Amazon dataset containing **89,082 records and 6 columns**. The data can be explored using Microsoft Excel and the provided Power BI dashboard template.

## 🎯 Project Objective

The main objectives of this project are to:

* Analyze Amazon product and order data.
* Understand product categories and pricing.
* Analyze customer review patterns.
* Examine shipment information.
* Analyze order dates and identify trends.
* Transform raw data into meaningful business insights.
* Present the analysis through data visualization and dashboards.

## 📁 Dataset

The project contains the following fields:

| Column                | Description                        |
| --------------------- | ---------------------------------- |
| `Product Category`    | Category of the Amazon product     |
| `Product Description` | Description/details of the product |
| `Price(Dollar)`       | Product price in US dollars        |
| `Number of reviews`   | Number of customer reviews         |
| `Shipment`            | Shipment-related information       |
| `Order Date`          | Date on which the order was placed |

**Dataset size:** 89,082 records and 6 columns.
